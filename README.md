# GiftFit

אפליקציית מובייל (אתר מותאם לטלפון) לבחירת מתנה לפי המקבל, האירוע, תחומי העניין, התקציב והמיקום. עברית, RTL.

## מה יש בה

- שאלון התאמה, חיפוש חופשי, תוצאות עם ״התאמות קרובות״ כשאין התאמה מלאה.
- קטלוג של מוצרים אמיתיים מחנויות ישראליות, עם קישור לעמוד המוצר בחנות.
- חשבונות (אימייל וסיסמה), מועדפים שמסתנכרנים בין מכשירים, ביקורות ודירוגים, תזכורות לאירועים.
- מסך ניהול קטלוג למנהלים: הוספה, עריכה ומחיקה של מוצרים.

## הפעלה מקומית

```
npm ci
npm run dev      # האתר וה-API יחד; מסד הנתונים בזיכרון ומתאפס בכל הפעלה
npm test         # בדיקות הדירוג, התזכורות וה-API
npm run build    # בדיקת טיפוסים, אריזת ה-API ל-api/index.js ובניית האתר ל-dist
```

כדי לבדוק מקומית את מסך הניהול: `ADMIN_EMAILS=me@example.com ADMIN_SETUP_CODE=code npm run dev`.

## מבנה

- `src/catalog.ts` – מודל המתנה, `recommend`, התאמות קרובות, חיפוש חופשי ואימות מוצר.
- `src/seed.ts` – קטלוג ברירת המחדל (מוצרים אמיתיים, מחירים נבדקו בתאריך שרשום בכל מוצר).
- `src/state.tsx` – מצב האפליקציה והחיבור ל-API. `src/storage.ts` – אחסון מקומי וניתוב.
- `src/screens.tsx`, `src/account.tsx`, `src/admin.tsx`, `src/components.tsx` – המסכים והרכיבים.
- `server/` – ה-API: `app.ts` (הלוגיקה), `store.ts` (Redis או זיכרון), `index.ts` (מתאם HTTP).
- `api/index.js` – ה-API ארוז עבור Vercel. נוצר ב-`npm run build:api`; לא לערוך ידנית.
- `public/figma` – לוגו ואייקונים מקובץ הפיגמה. `public/catalog` – איורים לפי קטגוריה.
- `test/` – בדיקות.

## פריסה ב-Vercel

משתני סביבה:

- `KV_REST_API_URL`, `KV_REST_API_TOKEN` – נוצרים אוטומטית כשמחברים לפרויקט מסד Upstash Redis. בלעדיהם האתר עובד עם הקטלוג המובנה, בלי חשבונות.
- `ADMIN_EMAILS` – כתובות המנהלים, מופרדות בפסיקים.
- `ADMIN_SETUP_CODE` – קוד שנדרש פעם אחת, בהרשמה של כתובת מנהל.

## מגבלות ידועות

- המחירים לא מתעדכנים לבד; מעדכנים אותם במסך הניהול. מוצרים שהיו במבצע זמני רשומים במחיר הרגיל של החנות.
- אין אימות אימייל ואין שחזור סיסמה (דורש שירות לשליחת אימיילים).
- התזכורות מוצגות בתוך האפליקציה (נקודה אדומה על הפעמון); אין התראות דחיפה.
- תמונות המוצרים הן איורים לפי קטגוריה, אלא אם הוזנה כתובת תמונה במסך הניהול.

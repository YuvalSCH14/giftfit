# GiftFit

אב־טיפוס לבחירת מתנה לפי המקבל, האירוע, תחומי העניין, התקציב והמיקום. עברית, RTL, מותאם לנייד (430px, נבדק גם ב־375px).

## הפעלה

```
npm ci
npm run dev      # שרת פיתוח, כתובת מודפסת בטרמינל
npm test         # בדיקות הדירוג והקטלוג
npm run build    # בדיקת טיפוסים ובנייה ל־dist
```

## מבנה

- `src/catalog.ts` – קטלוג ההדגמה (12 פריטים), המבנה `Search`, הפונקציה `recommend` ועזרי תצוגה.
- `src/storage.ts` – מועדפים ב־localStorage, ערכי השאלון ב־sessionStorage וניתוב לפי hash (`#search`, `#gift-care-kit`).
- `src/components.tsx` – כותרת עם תפריט צד, ניווט תחתון, כרטיס מתנה, לב שמירה וכפתור חזרה.
- `src/main.tsx` – ששת המסכים: בית, שאלון, תוצאות, פרטי מתנה, חנויות ומועדפים.
- `src/style.css` – עיצוב לפי מידות וצבעי המקור בפיגמה.
- `public/figma` – הלוגו והאייקונים שיוצאו מקובץ הפיגמה.
- `public/catalog` – איורים לפריטי ההדגמה ולעיגולי האירועים (אינם מהפיגמה).
- `public/manifest.webmanifest` והאייקונים – מאפשרים ״הוספה למסך הבית״ בטלפון.
- `test/catalog.test.ts` – בדיקות לתרחישי הקבלה.

## מגבלות הגרסה

- כל פריטי הקטלוג והחנויות הם נתוני הדגמה. לאף פריט אין קישור רכישה, ולכן מוצג ״מוצר לדוגמה״.
- הביקורות במסך פרטי המתנה הן תוכן המחשה ומסומנות כך.
- התראות ופרופיל מוצגים במצב לא פעיל.
- אין חשבונות, תשלומים, קטלוג חי או סנכרון בין מכשירים.
